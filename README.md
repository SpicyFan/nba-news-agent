# NBA News Agent

一个用于探索英文篮球新闻处理流程的个人项目原型。以新闻链接或正文为输入，辅助生成中文草稿和审核信息；最终内容需要人工核验，项目不自动发布到任何平台。

## 工作流程

单 Agent 根据输入解析新闻源，检索本地示例知识库，并在需要时查询篮球参考数据或网页；随后生成结构化草稿，执行规则检查，并根据检查结果修订。编辑负责最终事实核验与发布决策。

- **Prompt 与输出约束**：按新闻处理步骤组织提示词，要求区分事实、来源和待核验信息。
- **知识与数据**：使用本地文件检索示例规则和译名；动态数据可查询外部公开来源。
- **审核与人工复核**：规则检查帮助发现格式和证据缺口，不能保证所有事实正确；重要信息必须由人工确认。
- **接口**：提供命令行和 HTTP 接口；详细配置见 `.env.example` 和 `pyproject.toml`。

## 边界与说明

这是个人项目的 MVP，不代表虎扑官方系统，不连接虎扑后台，也不执行报备、查重或发布。本公开演示版中的写作规则是通用示例，未包含工作中使用的内部资料。因信源抓取、模型输出和外部数据可能不稳定，需以实际测试为准。

## 本地使用

需要 Python 3.11 及以上版本。安装项目依赖，将 `.env.example` 复制为 `.env`，在本地配置 API Key 和可用模型名称。不要将 `.env` 或密钥提交到公开仓库。完整端到端生成需要可用 API 和网络。

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
hupu-nba-agent 'https://example.com/article'
pytest
```

## 结构

- `src/hupu_nba_agent/`：Agent、提示词、接口与工具实现。
- `knowledge/`：公开演示用的通用知识样例和译名。
- `tests/`：离线单元测试。
